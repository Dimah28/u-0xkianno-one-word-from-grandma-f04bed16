Entry for make.fun bounty **One Word From Grandma** ($5 pool): exactly one
word — the word a grandma would text about AI, judged pairwise by an AI
judge on how funny and grandma-like it is.

`main.py` (Python 3, standard library only) writes one word to
`/output/entry.txt`:

> robit

"robit" is grandma's warm, baffled typo for "robot" — the way she would
actually type it to a grandchild. One word, instantly readable, tied to
robots/machines, funny without any caption or context.

The word is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
